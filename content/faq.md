## How do I uninstall Winutil?
* You do not have to uninstall Winutil. As it is a script you run from Powershell it only loads into your RAM. This means as soon as you close Winutil it will be deleted off your system.

## I applied a tweak and now something doesn't work, what do I do?
* If you applied a tweak and it breaks something, you can always revert the tweak by selecting the tweak and clicking "Undo Selected Tweaks".

## Winget is Broken / Repair dosn't work / Cannot install Programs
* Microsoft occasionally introduces changes that can disrupt the installation process of Winget. Unfortunately, there isn't a consistent method provided by Microsoft to repair Winget across different Windows and Winget versions. We are actively working on solutions, but success can vary.
To manually fix the problem, follow these steps:
- Download the latest stable version of Winutil. Ensure you select the .msixbundle file.
- Install the downloaded .msixbundle on your device.
- After installation, relaunch Winutil.
- Retry to install any application.
If you continue to experience issues, please open a Github Issue or contact support on the Community Discord Server.
